## Basic Cordapp Sample

This folder features basic sample projects, each of them demonstrates low level cordapp functionalities, such as [RPC connection](https://docs.corda.net/docs/corda-os/api-rpc.html#api-rpc-operations), messaging, etc.

### [Cordapp Example](./cordapp-example):
A simple exploratory sample for the official [Corda online training](https://training.corda.net).  

### [Database Access](./flow-database-access):
This CorDapp provides a simple example of how the node database can be accessed within flows. In this case, the flows maintain a table of cryptocurrency values in the node's database.  

### [Http Access](./flow-http-access):
This CorDapp provides a simple example of how HTTP requests can be made in flows. In this case, the flow makes an HTTP request to retrieve the original BitCoin readme from GitHub.  

### [Ping Pong](./ping-pong):
This CorDapp allows a node to ping any other node on the network, demonstrating stateless communication between nodes.  



Exemple de CorDapp de base

Ce dossier contient plusieurs projets d’exemple simples, chacun présentant des fonctionnalités de bas niveau des CorDapps, telles que la connexion RPC, la messagerie, etc.

Exemple de CorDapp

Un exemple simple d’exploration destiné à la formation officielle en ligne sur Corda.

Accès à la base de données

Cette CorDapp fournit un exemple simple montrant comment accéder à la base de données du nœud depuis les flows. Dans ce cas, les flows maintiennent une table contenant les valeurs de cryptomonnaies dans la base de données du nœud.

Accès HTTP

Cette CorDapp fournit un exemple simple montrant comment effectuer des requêtes HTTP depuis les flows. Dans ce cas, le flow effectue une requête HTTP afin de récupérer le fichier README original de Bitcoin depuis GitHub.

Ping Pong

Cette CorDapp permet à un nœud d’envoyer un ping à n’importe quel autre nœud du réseau, illustrant ainsi une communication sans état entre les nœuds.
